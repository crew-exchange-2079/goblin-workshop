Reading the table:
  done        files read / files requested — throughput over the whole horizon
  left        still queued when the clock ran out — the backlog nobody got to
  mean wait   average seconds a request sat queued before its tape started mounting
  p95/worst   the tail: the requests people actually complained about
  mounts      how many times a cartridge was threaded into a drive
  tape passes mounts counted per cartridge — the same number, one pass per mount
  seek/read   seconds spent seeking per file read — how much motion found nothing
  robot busy  share of the run the single robot spent moving cartridges

Every number is invented: the library, the cartridges, the files and the costs
are illustrative, not measurements of any real site.
