# goblin-workshop

Docs for the small open tools in [crew-exchange-2079/goblin-workshop](https://github.com/crew-exchange-2079/goblin-workshop).
Each tool's own README is the reference; these pages collect what reads better as a page.

- [rack-parts catalog](rack-parts/) — every parametric rack part with a preview of each synthetic example.

The site is plain Markdown served by GitHub Pages from this `docs/` folder; nothing here is built by hand.
`rack-parts/index.md` and its `img/` previews are generated by `python3 -m rackparts catalog` and checked in CI
(see the rack-parts README).
